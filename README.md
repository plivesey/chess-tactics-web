# Chess Tactics & Lessons website

Landing page, terms, privacy policy and tactic share links for the Chess Tactics & Lessons iOS app,
served at https://chesstacticsapp.com. See [CLAUDE.md](CLAUDE.md) for how the repo and deploy work.

```sh
npm install
npm start       # dev server
npm test        # route smoke tests
npm run build   # production build into build/
npm run deploy  # build and publish to GitHub Pages
```
